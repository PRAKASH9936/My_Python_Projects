### 2. To-Do List Application (`My_First_TO-DO_List_in_Python.py`)
A console-based application to manage daily tasks, track completion, and view summary statistics.

#### Features
* **Add Tasks:** Quickly add new tasks to your list.
* **View Tasks:** Check all current tasks with clear status indicators (`[Pending]` / `[Completed]`).
* **Complete Tasks:** Mark specific tasks as done using their task number.
* **Delete Tasks:** Remove unwanted tasks from the list.
* **Task Summary:** View real-time statistics including total, completed, and pending tasks.
